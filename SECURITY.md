# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.3.x   | :white_check_mark: |
| < 0.3   | :x:                |

## Reporting a Vulnerability

**Do not open a public issue for security vulnerabilities.**

Instead:

1. Use **GitHub → Security → Report a vulnerability** (private Security Advisory) on this repo, or
2. Contact the maintainer directly via GitHub [@pauloedspinho20](https://github.com/pauloedspinho20) (DM or email from profile).

Include: affected version/commit, reproduction steps, impact, and any suggested fix. We will acknowledge within 72 hours, assess, and coordinate a fix and disclosure. Please allow up to 90 days before public disclosure.

## Scope

C++ DSP core (`packages/core`), desktop shell (`apps/desktop`), plugin (`packages/vst3`), web app (`apps/web`), WASM boundary, and supply-chain (dependencies, workflows).

## Disclosure

Once a fix is available, a patched release and advisory will be published. Credit will be given if desired.
